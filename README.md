## Сервис предсказаний стоимости недвижимости (Regression Service)

Микросервис на **FastAPI**, который загружает предобученную модель регрессии и через HTTP API возвращает предсказания на основе входных признаков (данные о ценах на дома в Бостоне).  
Сервис упакован в **Docker**-контейнер, что гарантирует воспроизводимость и лёгкость развёртывания.

---

##  Особенности

- **Готовый к продакшну** контейнер с изолированным окружением.
- **Автоматическая документация API** (Swagger UI) по адресу `/docs`.
- **Строгая валидация входных данных** — проверка наличия всех необходимых признаков.
- **Healthcheck эндпоинт** для мониторинга состояния сервиса.
- **Воспроизводимость** — фиксированные версии всех зависимостей.

##  Технологии

| Компонент       | Технология                                      |
|----------------|-------------------------------------------------|
| Язык           | Python 3.12                                     |
| Веб-фреймворк  | FastAPI, Uvicorn                                |
| ML-библиотеки  | Scikit-learn (1.8.0), XGBoost (3.2.0)          |
| Обработка данных | Pandas (3.0.3), Joblib (1.5.3)                 |
| Контейнеризация| Docker
